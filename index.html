Controlo dos teus dados

A Agenda da Noiva guarda apenas os dados necessários para organizar o casamento. Sem uma conta, os dados permanecem neste navegador. Com uma conta, são sincronizados de forma privada entre os teus dispositivos.

Acesso e portabilidadePodes descarregar uma cópia integral em formato JSON.
RecuperaçãoAs alterações online mantêm versões de segurança para recuperação.
EliminaçãoPodes eliminar a conta e todos os dados associados.
Sem publicidadeNão existem cookies publicitários nem venda de dados.
Eliminar dados

Remove os dados guardados neste dispositivo.
